# 📚 StudyFlow

StudyFlow is a responsive study task manager built with HTML, CSS, and JavaScript.

It helps students organize their study tasks, track their progress, and manage completed and remaining tasks.

## ✨ Features

- ➕ Add new study tasks
- 💾 Automatically save tasks using Local Storage
- ✅ Mark tasks as completed
- ↩️ Undo completed tasks
- 🗑️ Delete tasks
- 🔎 Search tasks
- 🔘 Filter tasks:
  - All
  - Completed
  - Remaining
- 📊 Task statistics:
  - Total tasks
  - Completed tasks
  - Remaining tasks
- 🌙 Dark Mode
- ⌨️ Press Enter to add a task
- 📱 Responsive design for mobile devices

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage
- Git & GitHub

## 📱 Responsive Design

StudyFlow is designed to work on:

- 📱 Smartphones
- 💻 Laptops
- 🖥️ Desktop computers

## 🚀 How to Use

1. Enter a study task in the input field.
2. Click **Add Task** or press **Enter**.
3. Use **Done** to mark a task as completed.
4. Use **Undo** to restore a completed task.
5. Use **Delete** to remove a task.
6. Use the search bar to find a specific task.
7. Use the filters to display different types of tasks.
8. Use the 🌙 button to switch between light and dark mode.
