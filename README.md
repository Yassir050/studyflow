📖 Overview

StudyFlow is a modern, responsive, and multilingual study task manager designed to help students organize their study tasks, track progress, and stay productive.

The project is built with vanilla HTML, CSS, and JavaScript and focuses on creating a clean user experience while demonstrating practical frontend development skills.

⸻

✨ Features

📋 Task Management

* ➕ Add study tasks
* ✅ Mark tasks as completed
* ↩️ Undo completed tasks
* 🗑️ Delete tasks
* 💾 Automatically save tasks using Local Storage
* 🔒 Safe DOM-based task rendering

🔎 Search & Filtering

* 🔍 Search tasks instantly
* 📋 View all tasks
* ✅ View completed tasks
* ⏳ View remaining tasks
* ⚡ Filter tasks without reloading the page

📊 Progress Tracking

StudyFlow automatically displays:

* Total tasks
* Completed tasks
* Remaining tasks

Statistics update automatically whenever the task list changes.

💾 Data Storage

StudyFlow currently uses the browser’s Local Storage.

No account or backend is required.

Tasks and preferences are stored locally on the user’s device.

⚠️ Clearing the browser’s Local Storage can remove saved tasks and preferences.

Future versions may introduce cloud synchronization and user accounts.

⸻

🛡️ Security

StudyFlow uses DOM APIs such as textContent for rendering user-provided task content instead of inserting raw HTML.

This helps reduce the risk of unintentionally interpreting task text as HTML.
